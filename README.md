# RetroGame

Das Retro Game Projekt wurde von Schülern aus den 4. und 5. Klassen im Schuljahr 2026/27 für den Tag der offenen Türe erstellt. 
Die Grundidee war folgendes: Mittels einem ESP32 und einem VGA Monitor sollen Retro Games gespielt werden.

## Prototyping
Zuerst wurde ein VGA Kabel aufgeschnitten und Jumper angelötet um dieses an einen ESP32 anschließen. Zuerst wurde ein Testcode von Claude generiert 
um die Verbindung und das Konzept zu testen. 

## Das 3D Modell
Die beiden Controller sowie die Konsole selbst wurden in Siemens NX designt und über unseren 3D Drucker (H2D) ausgedruckt.

## 

## Die Hardware
Folgende Hardware wurde verwendet:
* NodeMCU-32s (ESP32)
* VGA female Stecker
* 2x Joysticks
* 8x Buttons
* Wiederstände
* 3x Headers
* Jumper
